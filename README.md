# Furina Agent

Windows x64 个人 AI 工作台。支持 DeepSeek API、OpenAI API 和 Codex 账户接入，提供对话、文档阅读、本地知识库、日程及内容导出。

这个独立版本不附带任何角色模型、武器、立绘、角色主题图片或音乐。不需要模型也能使用。用户可在设置中自行添加本地 GLB，在独立窗口旋转查看并播放文件自带动画。

## 下载与安装

进入本仓库右侧 **Releases**，展开版本的 **Assets**，下载 `Furina-Agent-0.1.0-x64-Setup.exe`。不要下载 GitHub 自动生成的 `Source code.zip`，它不是安装包。

双击安装器，选择安装目录，完成后打开 **Furina Agent**。首次使用进入 **设置 → 模型连接**，配置自己的 API Key 或 Codex 账户。

详细步骤见 [使用说明](使用说明.md)，验证范围见 [功能测试说明](功能测试说明.md)。本仓库只提供安装包与说明，暂不公开项目源码。

## 三种连接

| 连接方式 | 用户需要准备 | 首版能力 |
|---|---|---|
| DeepSeek | 自己的 DeepSeek API Key | 聊天、文档与知识库问答、总结、联网搜索、受限工具 |
| OpenAI API | 自己的 OpenAI API Key 与可访问的模型 | Responses API 聊天、文档与知识库问答、总结、联网搜索、受限工具 |
| Codex 账户（预览） | 官方 Windows Codex CLI 0.145+，在本应用内登录 | 聊天、文档与知识库问答、总结；不执行系统工具、记忆写入或联网搜索 |

OpenAI API 与 ChatGPT 订阅不是同一计费方式。Codex 可用性和额度以所登录账户为准。软件不附赠账户或额度，不内置共享密钥。

## 主要功能

- 多任务聊天、流式回复、停止、重新生成、历史记录、显式记忆。
- 本地读取 TXT、MD、JSON、CSV、LOG、带文字层的 PDF 和 DOCX；原始文档不上传，只发送所需文字。支持来源引用、全文总结和文件夹知识库。
- 本地待办、提醒与倒计时；回答及任务可导出 Markdown、DOCX、PDF。
- 本地备份、诊断、快捷入口、系统语音输入与朗读。语音依赖 Windows 已安装的语音组件。
- 浅色、深色、自选背景及界面缩放。
- 可选 GLB 查看器：旋转、缩放、动画选择、暂停与视角复位。

## 当前边界

这是首个无内置模型的预览版本，不能据此认为全部功能或全部外部模型均无问题。真实 Codex 账户回复、真实 OpenAI 请求和语音设备尚未在本版本完成端到端验收，具体见测试说明。

不包含旧桌宠的五套形象、专属动作和 2D 资源；导入模型不会自动获得旧版桌宠行为。没有 OCR、图片理解或离线语言模型。自动更新通道未配置，请从 Releases 手动下载版本。

Windows 安装器暂未进行正式代码签名，可能显示“未知发布者”。本项目为个人开发，不是米哈游、OpenAI 或 DeepSeek 官方产品。
